# Wallets and balances

A wallet is where your money lives: a bank account, e-wallet, investment, cash,
or a custom wallet. Every transaction belongs to one wallet.

## Add a wallet

1. Open **Wallets** from Home or Settings.
2. Tap **Add wallet**.
3. Pick a provider (BCA, GoPay, and so on) or **Add custom wallet**.
4. Fill in the display name, type, and opening balance if any.
5. Save.

The built-in **Cash** wallet is created automatically on first launch. If you
delete it, the Cash provider still appears in the add-wallet list.

## Opening balance and corrections

A wallet balance is calculated from the full transaction history, not typed by
hand.

- **Opening balance** is stored as an adjustment row noted "Saldo awal".
- **Balance correction** creates a new adjustment row. Old history is not
  changed.
- Opening balance and corrections cannot be edited from the wallet detail page.
  Create a new correction from the transaction screen.

If a balance looks wrong, check the transactions and transfers in that wallet
first, then add a correction only when needed.

## Allow negative balance

Turn on **Allow negative balance** in the wallet settings if you still want to
record expenses when the balance is not enough. A negative balance is shown in
red. Wallets without this option reject transactions that would make the
balance negative.

## Count in total money

Each wallet has a **Count in total money** option. Turn it off for wallets that
should not be added to Total Duit, for example a wallet holding someone else's
money.

## Primary wallet and sorting

- The **primary wallet** always appears at the top of the list.
- Sort the list by name, highest balance, or lowest balance.
- Switch between grid and list view.

## Archive and delete

- A wallet you no longer use can be deactivated and reactivated later.
- Deleting a wallet also deletes the transactions, budgets, and bills that use
  it. Transfers to other wallets are removed too, so other balances change.
- Deletion uses a countdown confirmation and offers **Undo**.
- Deleted data can be purged permanently from Settings.

## Transfer between wallets

1. Tap **+** and choose **Transfer**.
2. Pick the source and destination wallets.
3. Enter the transfer amount and an optional admin fee.
4. Review the preview, then save.

Transfer rules:

- The principal amount lands in the destination wallet as the transfer amount.
- The admin fee is recorded as a separate expense in the **Biaya Admin**
  category.
- The total leaving the source wallet is the transfer amount plus the admin fee.
- The principal is not counted as income or expense in reports. Only the admin
  fee counts as an expense.
